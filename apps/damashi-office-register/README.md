# 黛玛诗办公楼 · 合同发票登记（试用）

给老板在手机和电脑上试登记用。只登记**黛玛诗办公楼**。正德铝单板、黛玛仕之家店面不会自动纳入。

预置 BG-HT-001 至 BG-HT-012，状态都是**签署待核**，不是已生效。BG-HT-012（北京木之易弘天文化发展有限公司杭州分公司）工种待核；结算合计 53,050.63、最终价 53,000、已付款 25,000、尚欠款 28,000 都是模板载明，凭证和审定待核。这 25,000 不计入已核验已付，也不并入原来 8 份暂定价小计 873,942.93。

填写示例里的 12,500 / 5,000 / 7,500 只在「示例模式」，和正式台账分开。

## 共用试用

老板和同事打开单独发给他们的试用地址，输入单独发给他们的共用密码。不需要在每台设备上执行 `npm run dev`，也不需要连同一个 Wi-Fi。

正式台账存在服务端。一个人点「确认写入台账」之后，其他人刷新或重新打开页面，看到的是同一本台账。导出的 Excel 和 JSON 只作备份。示例模式里的 12,500 / 5,000 / 7,500 仍只留在当前浏览器，不会写进共用台账。

试用密码放在 Cloudflare 的 `TRIAL_PASSWORD` 密钥里，不写进仓库、页面或前端代码。本地试共用台账时，把 `.dev.vars.example` 复制为 `.dev.vars`，在里面填写密码，再执行：

```bash
cd apps/damashi-office-register
npm install && npm run trial
```

`npm run dev` 只在本机打开界面，没有共用台账。不要把这个应用部署到仓库现有的 GitHub Pages。

## 在电脑或手机上打开本机界面

```bash
cd apps/damashi-office-register
npm install && npm run dev
```

浏览器打开 `http://localhost:5173`。这只适合改界面，写入不会同步到别人。

## 怎么用

1. 首页选择合同生效件、发票或付款凭证，上传 PDF/照片，或先手工填写。
2. 确认页核对。识别出来但不确定的值标着待核，点「采用」或自己改过才会写入。不要把未知填成 0。
3. 点「确认写入台账」之后才进入合同清单、付款台账或开票登记。不确认，不会变成已生效或已核验已付。
4. 结算单选择 BG-HT-001 至 012。尚欠款只在最终价和已付款都是数字时才计算。质保金不出现在结算单上，只在付款条件和合同清单里。
5. 导出的 Excel 与待审工作簿的工作表、列对齐，是数值快照。

开票方、实际付款人和收款供应商分开填写。付款付给供应商。

试用网站要密码才能打开合同和金额，并且不会挂到现有的公开 Pages。密码和试用地址不要写进这个文件。
